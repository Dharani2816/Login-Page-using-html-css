🔐 Login Page UI
    A simple, responsive login page user interface built using HTML and CSS. It includes a modern layout with a smooth gradient background and supports the full user flow:

Register → Forgot Password → OTP Verification → Reset Password

🖼️ Preview
    The UI uses a gradient background by default.
    To use the optional background image, uncomment the relevant CSS lines in styles.css.

📂 Project Structure

├── index.html         # Login page
├── register.html      # Registration form
├── forgot.html        # Forgot password input
├── otp.html           # OTP verification
├── reset.html         # New password form
├── styles.css         # All UI styling
└── abstract-simple-colors-8k-1920x1080.jpg  # Optional background image

✨ Features

    🎨 Modern UI with Poppins font

    🌈 Gradient background with blurred card effect

    🔎 Clean input fields with focus highlights

🔐 Login form with:

    ✅ "Remember me" option

    🔁 "Forgot Password" link

    🔄 Full flow

    📝 Registration

    ❓ Forgot Password

    📩 OTP Verification

    🔑 Password Reset

💻 Technologies Used

    ⚙️ HTML5

    🎨 CSS3

    🅶 Google Fonts (Poppins)

    🚫 No JavaScript, pure frontend

🚀 How to Run

    📥 Download or clone this repository
 
    🌐 Open index.html in your browser

    🔗 Navigate across pages using the provided links/buttons

📌 Notes

    🖼️ To use the background image, uncomment the background CSS in styles.css

    📱 The site is fully responsive across all screen sizes
